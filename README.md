# WebDownloader

This project consists of a web scraping script to download and organize in dedicated folders the pages of the Dalian-based Japanese language newspaper Manshū Nippō (滿洲日報). The newspaper came under Japanese military control after the occupation of Manchuria and became the largest newspaper in the region.

The provided notebook allows to download and organize the PDF file documents uploaded on the Internet Archive, organizing content based on the year and month in which the newspaper was issued.

## Installation

Clone the repository and install requirements in a dedicated environment:

```bash
$ cd WebDownloader
$ pip install requirements.txt
```

Then, run the notebook cells to start downloading.
